## Оставшиеся обязательные ворота

1. Native clipboard replay текущего SHA: PNG с alpha и разные сторонние получатели; privacy flags; pause, app exclusions и конфликт горячих клавиш. Не ослаблять безопасный отказ при неизвестных форматах clipboard.
2. UI-тест полного/частичного отказа диска при обычном сохранении, помимо уже проверенного отклонения некорректного backup-файла на предыдущем SHA.
3. Полный downgrade старого EXE только в отдельной чистой Windows VM: старый fault-handler нельзя запускать поверх обычных пользовательских diagnostics.
4. На точном текущем EXE: production-like idle ≥10 минут, нагрузка 30–60 минут, циклы открытия/закрытия палитры, CPU/Private Bytes/handles/GDI/USER и готовность hotkey/UI. Старый idle и 96 изолированных запусков не заменяют этот прогон.
5. Чистая Windows без SDK/Desktop Runtime, production second-instance activation, sign-in autostart, sleep/resume, Explorer restart, RDP и elevated receiver. Нужна безопасная чистая среда.
6. Доступность текущего EXE: High Contrast, смешанный DPI/несколько мониторов, экранный диктор и живое переключение темы Windows.
7. Публикация: принять неизменный SHA → создать/проверить draft и тег → опубликовать Release → скачать анонимно по публичному URL → сверить SHA/размер и smoke именно скачанного EXE → обновить существующий сайт/changelog реальными ссылками, датой, размером, SHA и статусом подписи; затем проверить обе страницы и ссылки.

## Границы продукта и данных

Палитра остаётся компактной и локальной. `.prev` — предыдущая генерация файла, не downgrade-backup. DPAPI-backup привязан к Windows user/machine; file clips содержат пути, не копии файлов. Автоматическая вставка зависит от фокуса/UIPI и остаётся необязательной. Исключения приложений не распознают все пароли. SHA-256 подтверждает совпадение файла, но не издателя; текущий EXE не подписан. Цель остаётся активной, незакрытые проверки не объявляются PASS.
