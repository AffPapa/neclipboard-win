## Оставшиеся ворота

1. Проверить реальный конфликт `Ctrl+Alt+F9`: отказ регистрации и сохранение прежней клавиши; отдельно pause и исключения приложений.
2. Проверить PNG с alpha и разные нативные приёмники; не обходить fail-closed поведение для неизвестных clipboard форматов.
3. UI-тест отказа диска при сохранении и восстановления/миграции на текущем EXE.
4. Проверить downgrade старого EXE только в отдельной чистой Windows VM.
5. На текущем EXE выполнить 30–60 минут нагрузки и циклы открытия/закрытия с замерами CPU, Private Bytes, handles, GDI/USER.
6. Проверить чистую Windows без SDK/Desktop Runtime, второй экземпляр, автозапуск, sleep/resume, перезапуск Explorer, RDP и elevated receiver.
7. Проверить High Contrast, смешанный DPI/несколько мониторов, экранный диктор и живое переключение темы.
8. Выполнить guarded GitHub draft→publish, анонимно скачать EXE и license bundle, сверить SHA/размер и запустить smoke скачанного файла; затем обновить сайт/changelog фактическими ссылками и проверить их.

## Границы продукта и данных

Палитра хранит историю локально. `.prev` — предыдущая генерация файла, не downgrade-backup. DPAPI-backup привязан к Windows user/machine; file clips содержат пути, а не копии файлов. Автоматическая вставка экспериментальна и зависит от фокуса/UIPI. Исключения приложений не распознают все менеджеры паролей. Публикация не должна обозначаться как полностью принятая, пока открытые ворота не закрыты или явно не приняты владельцем продукта.
