## Оставшиеся ворота

1. Проверить конфликт `Ctrl+Alt+F9` корректным вводом в горячую клавишу, отказ `RegisterHotKey` и сохранение старой рабочей комбинации; выполнить pause и исключения приложений.
2. Проверить PNG с alpha, разные нативные получатели и privacy flags; не обходить безопасный отказ на неизвестных форматах clipboard.
3. UI-тест отказов диска при сохранении и восстановление из резервной копии/миграции на точной сборке.
4. Проверить downgrade старого EXE только в отдельной Windows VM с безопасными тестовыми профилями.
5. Выполнить 30–60 минут нагрузки, циклы открытия/закрытия окна и измерить CPU, Private Bytes, handles, GDI/USER.
6. На чистой Windows проверить второй экземпляр, автозапуск, sleep/resume, перезапуск Explorer, RDP, elevated receiver и отсутствие SDK/Desktop Runtime.
7. Проверить High Contrast, смешанный DPI/несколько мониторов, экранный диктор и живое переключение темы.
8. Выполнить guarded GitHub draft→publish с анонимной загрузкой/сверкой SHA, затем обновить и проверить публичный сайт/changelog.

## Границы продукта и данных

Палитра хранит историю локально. `.prev` — предыдущая генерация файла, не downgrade-backup. DPAPI-backup привязан к Windows user/machine; file clips сохраняют пути, не копии файлов. Автоматическая вставка экспериментальна и зависит от фокуса/UIPI. Исключения приложений не распознают все менеджеры паролей. В этой приёмке прошли основные текст/bitmap/file round-trip сценарии, но перечисленные выше ворота остаются открытыми. Не объявлять публичный релиз полностью принятым, пока они не закрыты или явно не приняты владельцем продукта как ограничения.
