# NeClipboard Win 0.2.0

Status: release candidate, not yet published. Public release date is assigned by GitHub when the verified draft is published.

## Improvements

- Native WPF application updated to .NET 10 LTS; self-contained Windows x64 distribution, no SDK required by users.
- Bounded cached previews and full-content search avoid repeated large text allocations.
- Visible search reset and simple text/image/file/pinned filters.
- Pause history for 15 minutes or one hour, with automatic resumption and a visible state.
- Configurable hotkey with conflict checking that preserves the previous registration.
- Clearer keyboard actions, readable status layout and theme-aware controls.
- Snippet validation appears inside the editor and preserves entered text on errors, including the combined snippet-size limit.
- Escape and keyboard hints follow the selected tab; an empty snippets list explains how to create a reusable text template.
- Snippet accessibility names use their actual titles.

## Reliability fixes

- Correct x64 Windows INPUT structure used for the optional paste shortcut.
- Deep snapshots for backup and ordered, coalesced history writes across clear/restore/exit.
- Strict validation and limits for stored history, settings, images and backups.
- Restore transaction with a rollback journal, encrypted data snapshots and startup recovery.
- Image PNG encoding moved off the UI thread after copying and freezing the WPF bitmap.
- Independent light/dark QA overrides are preserved during window initialization.
- Clean CI now builds the verification project explicitly and releases link to an exact tested commit.

## Data compatibility

Version 0.2.0 reads legacy 0.1.5 history/settings and writes versioned schema-1 envelopes. Before upgrading, create a backup with 0.1.5 if you need to return to that version. A 0.1.5 EXE cannot be assumed to understand new data files; restore a compatible pre-upgrade backup when downgrading. DPAPI backups are intended for the same Windows user and computer, not for cross-device migration.

## Distribution notes

The current build is unsigned. A SHA-256 file is provided for integrity verification; it is not a substitute for an authenticated publisher signature. Windows may show a SmartScreen warning. Do not disable system protection globally.

Automatic paste remains optional; Windows focus and elevation restrictions can require manual Ctrl+V. The files format stores paths, not copies of the referenced files. Native ARM64 and Windows 10 support are not claimed for this release.

Final test results and any remaining limitations must be reviewed before the draft is promoted to a public release.
