# NeClipboard Win

Локальная история буфера обмена для Windows: скопируйте текст, картинку или файлы, откройте историю, найдите нужное и скопируйте обратно. По умолчанию окно открывается по `Ctrl+Shift+V`; сочетание можно изменить.

## Статус и скачивание

**0.2.0 — кандидат выпуска, публичная публикация EXE ещё не подтверждена.** Репозиторий [AffPapa/neclipboard-win](https://github.com/AffPapa/neclipboard-win) создан; загрузка исходников, GitHub CI и выпуск проверяются отдельно. [Изменения кандидата](docs/releases/v0.2.0.md) ещё не означают, что версия выпущена; кнопка скачивания появится после проверки настоящего публичного файла.

Планируемый формат распространения — один `NeClipboardWin-win-x64.exe` в [Releases](https://github.com/AffPapa/neclipboard-win/releases). Установка .NET, SDK, аккаунт и права администратора для обычного запуска не нужны. В релиз также входят файл `.sha256`, `release-manifest.json` с версией и происхождением сборки и сопроводительный `NeClipboardWin-LICENSES.txt`.

- Целевая платформа: **Windows 11 x64**. Windows 10 и native ARM64 в этом выпуске не заявлены поддерживаемыми.
- Текущий кандидат не подписан сертификатом издателя. Windows может показать предупреждение SmartScreen; контрольная сумма не заменяет подтверждённую личность издателя.
- После загрузки из подтверждённого релиза сравните SHA-256 с опубликованным файлом:

```powershell
Get-FileHash .\NeClipboardWin-win-x64.exe -Algorithm SHA256
```

## Возможности кандидата 0.2.0

- История текста, PNG-изображений и списков файлов; сохраняются пути к файлам, а не сами файлы.
- Поиск по полному тексту, очистка запроса, фильтры «Текст», «Картинки», «Файлы» и «Закреплённые».
- Закрепление, удаление, очистка истории; создание и редактирование текстовых сниппетов.
- Копирование выбранного элемента по Enter. Автоматическая вставка включается отдельно и зависит от фокуса и ограничений Windows.
- Изменение горячей клавиши с проверкой конфликта; открытие и выход через трей.
- Пауза на 15 минут или час, автоматическое возобновление, постоянное отключение сбора в настройках.
- Исключения приложений и обработка маркера конфиденциальности clipboard. Это не гарантирует обнаружение любого пароля.
- Светлая/тёмная тема следует Windows; предусмотрена системная высокая контрастность.
- Локальное DPAPI-хранилище, резервные копии и восстановление с журналом возврата после сбоя.
- Автозапуск по выбору пользователя и активация уже работающего экземпляра.

История ограничена числом записей (10–1000, по умолчанию 200) и суммарным объёмом. Закрепление не отменяет общий лимит: если других записей уже нет, ограничение может затронуть и закреплённые элементы. Изображения ограничены 8 миллионами пикселей и 3 MiB PNG, текст — 500 000 символами. Программа не хранит форматирование HTML/RTF, PDF-документы, аккаунты или облачную синхронизацию.

## Первые действия

1. Поместите EXE в постоянную папку и запустите.
2. Скопируйте обычный текст или изображение.
3. Откройте историю по `Ctrl+Shift+V`, найдите запись, выберите стрелками и нажмите Enter или «Скопировать».
4. Вернитесь в нужную программу и вставьте через `Ctrl+V`.
5. При необходимости измените сочетание, исключения, лимит и автозапуск в «Настройках».

Если включена автоматическая вставка, Windows может запретить имитацию клавиш для окна с повышенными правами или не передать ему фокус. Содержимое останется в буфере для ручного Ctrl+V. Приложение не нужно запускать администратором ради вставки.

## Данные, backup и обновление

Данные находятся в `%LOCALAPPDATA%\NeClipboard Win`. История, настройки, сниппеты и содержимое backup защищены Windows DPAPI CurrentUser. Обычно это та же учётная запись Windows на том же компьютере; перенос между компьютерами/пользователями таким backup не поддерживается. DPAPI не защищает от любого процесса с правами этого пользователя и не скрывает открытый clipboard от других приложений.

Перед переходом с 0.1.5 создайте backup именно в 0.1.5, если нужен возврат. Версия 0.2.0 читает старые данные и записывает версионированные документы schema 1. **Не открывайте новые рабочие файлы старым EXE**: 0.1.5 не рассчитана на эту схему. Для отката нужны сохранённая старая программа и совместимые данные до обновления; сначала закройте работающий экземпляр. Backup, созданный после обновления, не следует считать проверенным способом отката.

При обычном обновлении закройте программу через трей, замените EXE в той же папке и запустите новую версию. Данные хранятся отдельно. Если перемещаете EXE, заново примените автозапуск в настройках, чтобы Windows использовала новый путь.

## Сборка и проверки

Разработчику нужен .NET SDK, выбранный в `global.json`: **10.0.401**, совместимый patch той же SDK feature band. Приложение остаётся нативным WPF; встроенного Chromium и серверной части нет.

```powershell
dotnet build -c Release -warnaserror -p:RestoreLockedMode=true
dotnet run -c Release --project tests\NeClipboardWin.Verification\NeClipboardWin.Verification.csproj
.\scripts\public-preflight.ps1
.\scripts\release-test-preflight.ps1
.\scripts\release-build.ps1 -OutputDirectory .\artifacts\local-0.2.0
```

Последняя команда требует пустую выходную папку, явно собирает приложение и verification-проект, выполняет проверки, публикует self-contained EXE, запускает isolated smoke и создаёт manifest/checksum. Готовый файл: `artifacts\local-0.2.0\NeClipboardWin-win-x64.exe`. Локальная незафиксированная сборка помечается `uncommitted`, её нельзя выдать за релиз проверенного commit.

`tests/run-isolated-smoke.ps1 -ExecutablePath <путь-к-EXE>` проверяет ограниченный скрытый запуск светлой и тёмной темы на одноразовом профиле. Он отключает clipboard, tray, глобальную клавишу и автозапуск; это **не** доказательство работы вставки, реальных кликов или доступности. Окончательный файл проходит отдельную desktop/upgrade-приёмку до публикации.
